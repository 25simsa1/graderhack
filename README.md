# GraderHack, NTI GStar Bootcamp 2026

My individual project for the NTI GStar Bootcamp. It asks whether training on tasks that can't be solved honestly makes small models more likely to cheat the grader that scores them.

## What's here

- `repo/` has the environment, hack detector, pilot runner, RL-lite trainer and Slurm scripts. Its own README has the setup and results.
- `pitch/` has the original project proposal.
- `slides/` has the two-slide deck. v3 is the final version shown at the presentation. `slides/build/` has the script that builds it with python-pptx.
- `PLAN.md` is the sprint plan from presentation day, and `NUMBERS.md` is every number on the slides with its source run.
- `SCRIPT.md`, `QA.md` and `meeting-guide.md` (also as HTML) are my presentation script and Q&A prep.

Run transcripts and adapters stay on the Colby cluster and aren't in this repo.
